# Changelog

## 0.1.0

- First release: region-aware consent (opt-in, opt-out, notice), Global Privacy Control, Google Consent Mode v2, service presets (GTM, GA4, Google Ads, Meta, LinkedIn, HubSpot, Clarity, custom), click-to-load embeds, consent log, cookie declaration, theme template overrides, GitHub updates. Services from the theme and the admin load together, and services run on the live site only by default.
